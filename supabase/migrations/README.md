# supabase/migrations

ডাটাবেসের সব টেবিল ও নিয়মের SQL এখানে থাকবে — পরিকল্পনার §৪ (ডাটা মডেল) অনুযায়ী।

- প্রতিটা মাইগ্রেশন ফাইলের নাম: `0001_বর্ণনা.sql`, `0002_বর্ণনা.sql` … ক্রমানুসারে।
- Phase 1 থেকে মাইগ্রেশন যোগ হবে (sellers, shops, products, orders, subscription_plans …)।
- সব টেবিলে `seller_id` থাকবে যেখানে সেলারের ডাটা, আর Row Level Security (RLS) দিয়ে নিয়ম বাঁধা থাকবে — একজন সেলার আরেকজনের ডাটা কোনোভাবেই পড়তে পারবে না।
- মাইগ্রেশন চালানো: `supabase db push` (Supabase CLI) — বিস্তারিত `docs/setup.md`-এ আসবে।

Phase 0-এ এই ফোল্ডার ফাঁকা — কোনো টেবিল এখনো বানানো হয়নি।
